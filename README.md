# Диспетчер закупок

**Порядок в закупках и контроль запасов — в одном мобильном приложении.**

«Диспетчер закупок» — концепция мобильного приложения для самозанятых, индивидуальных предпринимателей, небольших магазинов и других представителей малого и среднего бизнеса. Проект предназначен для того, чтобы собрать учёт поставщиков, товаров, закупок и складских остатков в одном удобном месте.

## Рекламное описание проекта

Устали вести остатки в разрозненных таблицах и вспоминать, у какого поставщика заказывали нужный товар? «Диспетчер закупок» поможет навести порядок в закупках и складском учёте.

Храните информацию о поставщиках, ведите каталог товаров, планируйте закупки и следите за остатками на складе. Контролируйте минимальное количество товаров и сроки годности, добавляйте фотографии продукции и быстрее находите позиции по штрихкоду. Приложение ориентировано на повседневные задачи небольшого бизнеса: меньше ручной рутины — больше контроля над запасами.

**«Диспетчер закупок» — ваш мобильный помощник для управления товарами, поставщиками и закупками без сложных корпоративных систем.**

> На текущем этапе это описание концепции. Перечисленные возможности являются планами разработки и пока не реализованы.

## Целевая аудитория

- самозанятые;
- индивидуальные предприниматели;
- небольшие магазины и торговые точки;
- представители малого и среднего бизнеса, которым нужен простой учёт товаров и закупок.

## Планируемые возможности

- **Поставщики:** название или ФИО, ИНН, телефон, электронная почта, адрес и рейтинг.
- **Каталог товаров:** наименование, артикул, штрихкод, категория, производитель, описание, цена, количество, срок годности и фотография.
- **Закупки:** выбор поставщика и товаров, дата закупки и поставки, количество, цена за единицу, общая сумма и номер счёта.
- **Склад:** просмотр текущих остатков и даты последнего обновления.
- **Контроль запасов:** уведомления о минимальном остатке и приближающемся сроке годности.
- **Фотографии:** добавление изображения товара с помощью камеры или галереи.
- **Поиск по штрихкоду:** быстрый поиск товара с помощью камеры устройства.

## Основные сущности

| Сущность | Назначение |
|---|---|
| Supplier | Данные поставщика и контактная информация |
| Product | Карточка товара и его характеристики |
| Purchase | Информация о закупке и её составе |
| Warehouse | Текущее количество товара и дата обновления остатков |

## Запуск проекта

1. Скачайте репозиторий или клонируйте его командой:
   git clone https://github.com/Yoti-k/purchase-manager.git
2. Откройте Android Studio.
3. Выберите **Open** и укажите вложенную папку purchase-manager (внутри корня репозитория).
4. Дождитесь синхронизации Gradle. Для сборки потребуется установленный JDK 17 и Android SDK 35.
5. Запустите приложение на эмуляторе или Android-устройстве.
